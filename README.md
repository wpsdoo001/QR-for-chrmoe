# 图片二维码识别 · Chrome 插件

在网页图片上点击右键，选择「识别二维码」，即可解码图片中的二维码并在弹窗中显示内容。

## 安装（加载已解压的扩展程序）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `qr-code-reader`
4. 工具栏出现蓝色二维码图标即安装成功（建议在扩展列表里点「固定」）

> 无需打包 crx、无需应用商店，本地加载即可长期使用。更新代码后回到 `chrome://extensions/` 点该插件的刷新按钮。

## 使用

1. 在任意网页的图片上点击右键
2. 菜单里选择「识别二维码」
3. 页面中央弹出结果弹窗：识别中 → 显示内容
   - 「复制内容」把解码文本复制到剪贴板
   - 「打开链接」在内容为网址时出现
   - 关闭方式：点击「关闭」、右上角 ✕、点击遮罩、按 Esc

识别失败会直接提示原因（例如「未在这张图片中找到二维码」），不会静默无反馈。

## 支持的能力

| 场景 | 说明 |
| --- | --- |
| 普通网页图片 | 支持 http/https 图片地址，含 CDN、带防盗链的图片（后台请求携带 Cookie/Referer） |
| data: 内嵌图片 | 支持 base64 内嵌的图片 |
| blob: 图片 | 后台无法请求时，自动改由页面内取图并转 dataURL |
| 二维码只占大图一角 | 整体多尺度扫描 + 2×2 重叠切块二次扫描 |
| 小尺寸/模糊二维码 | 自动放大 2~4 倍再识别 |
| 反色二维码 | 解码时同时尝试正常与反色 |
| 受限页面 | chrome:// 等无法注入脚本的页面，改用独立小窗口显示结果 |

## 文件结构

```
qr-code-reader/
├── manifest.json     # MV3 配置：右键菜单、脚本注入、存储权限
├── background.js     # 右键菜单注册 + 取图 + OffscreenCanvas 解码主流程
├── qr-scan.js        # 解码核心（多尺度候选、纯逻辑，便于单测）
├── jsQR.js           # 第三方二维码解码库（jsQR，MIT）
├── content.js        # 页面内结果弹窗 + 页内取图兜底
├── dialog.html/js    # 受限页面下的独立结果窗口
├── popup.html        # 点击工具栏图标显示的用法说明
└── icons/            # 16/48/128 图标
```

## 实现要点

- **MV3 Service Worker 内解码**：后台 `fetch` 不受页面 CORS 限制，再通过 `createImageBitmap` + `OffscreenCanvas` 取像素，交给 jsQR 识别，避免污染 canvas 的问题。
- **多尺度 + 切块**：先按原尺寸、1200px、放大 2~4 倍多个候选绘制，全部失败后对大图做 2×2 重叠切块，显著提升“二维码只占画面一角”的命中率。
- **弹窗动画只用 transform，不用 opacity**：避免标签页在后台或动画被暂停时弹窗停留在透明状态。
- **样式隔离**：弹窗 DOM 挂载在独立根节点，样式带 `qrs-` 前缀，支持系统深色模式，不污染页面原有样式。

## 权限说明

- `contextMenus`：注册「识别二维码」右键菜单
- `scripting`：向当前页面注入结果弹窗脚本
- `storage`：受限页面下把小窗口所需的结果临时存一下
- `host_permissions: <all_urls>`：后台请求任意图片地址（跨域取图）所必需

## 常见问题

**右键没有「识别二维码」？**
确认右键的目标是图片本身（不是文字或空白区域）；安装后如菜单未出现，重启一次 Chrome 或到扩展页点刷新。

**提示「图片受跨域保护，无法读取像素」？**
极少数图片既不能被后台请求、也不能在页面内读取。可先右键「图片另存为」，再用本地图片识别。

**识别很慢？**
超大图会先压缩再识别，通常在 1 秒内完成；极端大图（4000px 以上）会做切块二次扫描，略慢属正常。

**支持条形码（一维码）吗？**
当前只识别二维码（QR Code）。如需一维码可换用支持 BarcodeDetector 的实现。
